# 🚀 快速开始 - 新前端使用指南

## 两种使用方式

### 方式一：开发模式（推荐先试这个）⭐

需要**两个终端**：

**终端 1** - 启动后端服务器：
```bash
npm start
```

**终端 2** - 启动前端开发服务器：
```bash
npm run frontend:dev
```

然后打开浏览器访问：**http://localhost:3000**

---

### 方式二：生产模式（整合在一起）

如果想让后端直接服务前端页面：

```bash
# 1. 先构建前端（需要先解决一些构建问题）
npm run frontend:build

# 2. 启动服务器
npm start
```

然后打开浏览器访问：**http://localhost:7187**

---

## 📋 前置条件

- Node.js >= 20.0.0
- 前端依赖已安装（运行过 `npm run frontend:install`）

## 🎯 新前端特性

- ✅ React + TypeScript，现代化技术栈
- ✅ Semi Design 组件库，界面美观
- ✅ 完整的 Markdown 渲染支持
- ✅ WebSocket 实时通信
- ✅ 流式响应显示
- ✅ 连接状态指示器

## 🔧 故障排除

如果前端无法启动：
1. 确认端口 3000 未被占用
2. 确认已运行 `npm run frontend:install` 安装依赖

如果无法连接后端：
1. 确认后端已在运行（npm start）
2. 确认后端端口是 7187
