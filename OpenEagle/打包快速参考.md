# 📦 项目打包快速参考

## 最简单的方式（推荐）

### 你有 Docker → 用 Docker 镜像打包

```bash
# Windows
scripts\package-docker.bat v1.0

# Mac/Linux
chmod +x scripts/package-docker.sh
scripts/package-docker.sh v1.0
```

**得到**：`pi-agent-v1.0.tar.gz`

**对方使用**：
```bash
docker load -i pi-agent-v1.0.tar
docker volume create pi-agent-data
docker run -d --name pi-agent -p 7187:7187 -v pi-agent-data:/app/workspace -e ANTHROPIC_API_KEY=你的key pi-agent:v1.0
```

---

### 对方有 Node.js 但没 Docker → 源代码打包

```bash
# Windows
scripts\package-source.bat v1.0

# Mac/Linux
chmod +x scripts/package-source.sh
scripts/package-source.sh v1.0
```

**得到**：`example-embedded-pi-source-v1.0.tar.gz`（或 .zip）

**对方使用**：
```bash
tar xzf example-embedded-pi-source-v1.0.tar.gz
cd example-embedded-pi-source-v1.0
npm install
cp .env.example .env
# 编辑 .env 填入 API Keys
npm start
```

---

## 📋 所有打包脚本

| 脚本 | 平台 | 说明 | 输出文件 |
|-----|------|------|---------|
| `scripts/package-docker.bat` | Windows | Docker 镜像打包 | `pi-agent-v1.0.tar` + `.zip` |
| `scripts/package-docker.sh` | Mac/Linux | Docker 镜像打包 | `pi-agent-v1.0.tar.gz` |
| `scripts/package-source.bat` | Windows | 源代码打包 | `example-embedded-pi-source-v1.0.zip` |
| `scripts/package-source.sh` | Mac/Linux | 源代码打包 | `example-embedded-pi-source-v1.0.tar.gz` |
| `scripts/backup-data.bat` | Windows | 数据备份 | `backups/pi-agent-backup-xxx.tar.gz` |
| `scripts/backup-data.sh` | Mac/Linux | 数据备份 | `backups/pi-agent-backup-xxx.tar.gz` |

---

## 🎯 选择指南

| 你的场景 | 用什么 |
|---------|-------|
| 给客户部署，省事 | Docker 镜像 |
| 给开发者，他们会自己装依赖 | 源代码打包 |
| 对方机器没网络 | 完整打包（看 PACKAGING_GUIDE.md） |
| 只是想备份数据 | backup-data 脚本 |
